# vue3-admin-tutorial 🎓

> 《给 Java 程序员的 Vue3 全栈入门——Mini 管理后台实战》
> 一个专为 **Java 后端转全栈** 程序员设计的 Vue3 教学项目：一个可运行的 Mini 管理后台 + 13 章精读文档。

**🚧 项目正在编写中** —— 完整的学习路线图、快速开始与知识覆盖地图将随后续提交逐步补全。

## 初步规划

- 技术栈：Vue 3 + TypeScript + Vite + Vue Router + Pinia + Axios
- 业务场景：登录鉴权、仪表盘、用户管理、文章管理、个人设置
- 教学特色：全程用 Java/Spring 类比讲解前端概念

## 目录结构（规划）

```
docs/    # 13 章精读文档
src/     # 可运行的 Mini 管理后台源码
```
